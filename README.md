# Bonavita Lavanderia — Site demonstrativo

Protótipo comercial (somente frontend) desenvolvido pela V3X Digital Product Studio.

## Executar
```bash
cd bonavita-lavanderia
python -m http.server 5173
# abrir http://localhost:5173
```
(Também funciona abrindo `index.html` direto no navegador.)

## Estrutura
- `index.html` — conteúdo e seções
- `styles.css` — identidade visual (variáveis de cor/tipografia no topo)
- `main.js` — menu, status "aberto agora", animações, montador de pedido via WhatsApp
- `assets/img/` — imagens ilustrativas (substituir por fotos reais da loja)
