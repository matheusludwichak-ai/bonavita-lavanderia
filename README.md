# Bonavita Lavanderia — Site Demonstrativo Comercial

Protótipo comercial de frontend desenvolvido pela **V3X Digital Product Studio** para apresentação comercial à empresa Bonavita Lavanderia (Jaraguá do Sul – SC).

- 🌐 **Deploy na Vercel (Produção):** [https://bonavita-lavanderia.vercel.app](https://bonavita-lavanderia.vercel.app)
- 📦 **Repositório GitHub:** [https://github.com/matheusludwichak-ai/bonavita-lavanderia](https://github.com/matheusludwichak-ai/bonavita-lavanderia)

---

## 🚀 Como Executar Localmente

### Via Servidor Python
```bash
cd bonavita-lavanderia
python -m http.server 5173
# Abra no navegador: http://localhost:5173
```

Ou simplesmente abra o arquivo `index.html` em qualquer navegador.

## 🎨 Identidade Visual e Recursos Desenvolvidos

1. **Logo Oficial Bonavita®:**
   - Logotipo oficial vetorizado e com transparência de alta definição (`assets/logo-bonavita.png`), preservando os efeitos característicos das letras e o acabamento original da marca.
   - Versão clara para o rodapé escuro (`assets/logo-bonavita-light.png`).
   - Favicon oficial configurado (`assets/favicon.png`).

2. **Experiência e Intuitividade (UX/UI):**
   - **Simulador Interativo com Live Preview:** Conforme o usuário escolhe as peças e método de entrega (Leva e traz vs. Loja), uma caixa de mensagem no estilo WhatsApp é atualizada em tempo real com o texto pronto.
   - **Ações Rápidas nos Serviços:** Cada card de serviço ("Edredons", "Tapetes", "Cortinas", "Ternos", etc.) possui um botão *"Incluir no orçamento"* que rola suavemente até o simulador e já marca aquele serviço automaticamente.
   - **Botão Flutuante do WhatsApp (Desktop & Mobile):** Botão fixo com tooltip *"Precisa de ajuda? Chame aqui!"* para contato instantâneo.
   - **Status "Aberto agora":** Verificação dinâmica em tempo real com base no horário comercial da empresa (seg a sex: 8h30–18h30; sáb: 8h30–12h30).
   - **Localização Direta:** Botões para traçar rota no Google Maps e Waze para a Rua Cel. Procópio Gomes de Oliveira, 101 – Centro.
